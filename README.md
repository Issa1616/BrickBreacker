# BrickBreaker

BrickBreaker es un videojuego desarrollado en **Unity** como parte de un proyecto académico. El objetivo principal es destruir todos los bloques de cada nivel utilizando una pelota que rebota dentro del escenario.

El juego cuenta con diferentes niveles y mecánicas que aumentan la dificultad conforme se avanza.

## Características

- Juego tipo **Brick Breaker**.
- 2 niveles disponibles.
- Sin sistema de vidas.
- La pelota rebota contra las paredes y los bloques.
- Los bloques desaparecen al recibir un impacto.
- Los controles se invierten si atrapas un cubo blanco.

## Controles

| Tecla | Acción |
|---|---|
| `←` | Mover la plataforma a la izquierda |
| `→` | Mover la plataforma a la derecha |

## Ejecución

Para ejecutar el proyecto:

1. Clonar el repositorio.

```bash
git clone https://github.com/Issa1616/BrickBreacker.git
```

2. Abrir **Unity Hub**.
3. Seleccionar **Add project from disk**.
4. Elegir la carpeta del proyecto.
5. Abrir el proyecto con una versión compatible de Unity.
6. Abrir la escena principal.
7. Presionar **Play** para comenzar.
